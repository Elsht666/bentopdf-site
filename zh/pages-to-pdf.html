常见问题

Do I need a Mac or the Pages app to convert a .pages file?

No. The conversion runs on a LibreOffice engine inside your browser, so it works on Windows, Linux, Chromebooks, and Macs without Pages installed.

Why is the first Pages document slow to convert?

The engine has to be downloaded on first use, around 75 MB compressed, and then started. Later conversions in the same session reuse it and start right away.

Can I convert several Pages documents at once?

Yes. Add multiple .pages files and click Convert to PDF; you get pages-to-pdf.zip with one PDF per document. Files that share a name get a numbered suffix such as Report (1).pdf so nothing is overwritten.

Will the PDF look exactly like it does in Pages?

Usually close, but not guaranteed. A LibreOffice import filter reads the file rather than Pages itself, so complex layouts, some fonts, and newer Pages features may render differently. Check the output before sending it on.

What will the PDF be named?

The same base name as the Pages document with a .pdf extension, so Resume.pages becomes Resume.pdf.

What should I do if the conversion fails?

An error message shows the reason the engine reported. Make sure the file is a real .pages document and not corrupted; if it still fails, open it in Pages and export it again, or export to PDF from Pages directly.

Can I convert a Pages file to Word instead of PDF?

This tool only produces PDF. If you need a .docx, convert the Pages file here first and then run the result through PDF to Word.

Is my Pages document uploaded to a server?

No. The LibreOffice engine reads and renders the document in your browser; the only network transfer is downloading the engine itself. Your file never leaves your device.
