Câu hỏi thường gặp

Can I combine several BMP files into one PDF?

Yes. Every BMP you add becomes its own page in a single PDF, in the order shown in the file list. There's no option to produce one PDF per file, so convert files separately if you need them split.

Why is the PDF smaller than my BMP files?

BMP stores uncompressed pixels, so the files are large. The converter redraws each image and stores it in the PDF as lossless PNG, which usually shrinks it considerably without changing a single pixel.

Is any image quality lost in the conversion?

No. Pixels are stored losslessly and there's no quality setting on this tool, so the output has the same resolution and colors as the source. If you need a smaller file afterward, run the PDF through Compress PDF.

What page size does the PDF get when I convert a BMP?

Each page is sized to the image's pixel dimensions at one point per pixel, so a 2480 by 3508 pixel scan produces a page about 34 by 49 inches rather than A4. Viewers and printers scale it to fit, and Fix Page Size can resize every page to A4 or Letter afterward.

Why does it say one of my files is invalid?

Images are decoded by your browser, which handles standard Windows bitmaps. Unusual variants such as OS/2 headers or rare compression modes can fail; re-saving the file as a standard 24-bit BMP or as PNG in any image editor fixes it.

Can I mix BMP with JPG or PNG files?

This tool accepts only .bmp files and skips anything else you add. Use Images to PDF when you need to combine several formats into one document.

Does the BMP's DPI setting affect the result?

No. The resolution stored in the file header is ignored and page size comes purely from pixel count, so two images with the same pixel dimensions produce identical pages regardless of their DPI.

Are my BMP files uploaded anywhere?

No. Decoding uses your browser's own image support and the PDF is assembled locally with pdf-lib, so scanner or medical imaging exports never leave your computer.
