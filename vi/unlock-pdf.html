Câu hỏi thường gặp

Can Unlock PDF remove a password I don't know?

No. It needs the current password and doesn't crack, guess, or brute-force anything. If the PDF opens without a password but blocks printing or copying, use Remove Restrictions instead.

Does it work with the owner password or only the open password?

Either. Enter whichever password you have; the tool authenticates with it and saves a copy with the encryption removed entirely, so no residual restrictions remain.

Can I remove the password from several PDFs at once?

Yes, as long as they share the same password. Upload them all, enter the password once, and you get decrypted-pdfs.zip with the files under their original names. PDFs with different passwords need separate batches; any file that fails is counted in the summary while the rest still download.

Why do I get a password error?

The password didn't match the file. Check caps lock and trailing spaces, and make sure you're using this file's password rather than one from a similar document. A damaged file shows a Decryption Failed message instead; Repair PDF may help there.

Will removing the password change the document?

No. Pages, text, images, forms, and bookmarks are kept; only the encryption layer is removed, and the file keeps its name. The output has no security at all, so re-protect it with Protect PDF if it needs a new password.

Why would I remove the password from my own PDF?

Common reasons: a document management system that rejects encrypted files, merging with other PDFs (many merge tools can't read encrypted input), long-term archiving, or a password that's no longer needed.

Is my password or file sent anywhere?

No. Decryption runs in your browser with WebAssembly PDF engines (CoherentPDF, with PyMuPDF as a fallback), so the file and the password stay on your device.

Is this the same tool that was called Decrypt PDF?

Yes. Decrypt PDF was renamed to Unlock PDF; it's the same tool with the same behavior.
