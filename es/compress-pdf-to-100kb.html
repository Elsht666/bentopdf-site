Alerta

To compress a PDF to 100KB, add your file below, choose the Aggressive or Extreme compression level, and download the smaller file. Everything runs inside your browser. the PDF is never uploaded to a server, so even sensitive documents like ID scans and application forms stay on your device.

When you need a PDF under 100KB

A 100KB cap is common on job application portals, government e-filing systems, university admission forms, and visa or immigration websites. These systems usually reject larger files outright, often without a helpful error message, so compressing before you upload saves a failed submission.

What to expect at 100KB

A text-based PDF of a few pages. a resume, cover letter, or typed form. compresses below 100KB easily with no visible change. Scanned documents and photo-heavy files are harder: to hit 100KB they need stronger image downscaling, so expect visibly softer images. If your scan will not reach 100KB with the Extreme level, try the Photon mode, which rebuilds each page as an optimized image, or split the document and compress the pages you actually need to submit.

Tips for the smallest possible file

Remove pages you do not need before compressing. Prefer documents exported straight from an editor over scans. a re-typed one-page form is often 20KB while the same page scanned is 500KB. If you control the scanner, scan at 150 DPI in grayscale instead of 300 DPI color.

Preguntas frecuentes

Can every PDF be compressed to 100KB?

Not always. Short text-based PDFs almost always can. Long or heavily scanned documents may bottom out above 100KB even at Extreme level. in that case split the file or rescan at a lower DPI and compress again.

Which compression level should I pick for 100KB?

Start with Aggressive. If the result is still over 100KB, run Extreme, and for scans try Photon mode. You can compress the same file repeatedly with different levels. nothing is uploaded, so retries are instant.

Will my text stay selectable?

With the standard Condense engine, yes. text, links, and form fields are preserved. Photon mode converts pages to images, so text is no longer selectable; use it only when a scan refuses to shrink.

Is my document private?

Yes. Compression runs entirely in your browser using WebAssembly. The file never leaves your device, which matters for the ID documents and applications that 100KB limits usually involve.
