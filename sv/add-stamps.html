Vanliga frågor och svar

What kind of stamps can I add with this tool?

This tool places image stamps, so you pick an image file such as a PNG or JPG (a company seal, an APPROVED graphic, a scanned notary stamp) and drop it onto the page. For text-only marks like a diagonal DRAFT label, Add Watermark is the better fit.

What does the Stamp Username field do?

The name you enter is recorded on each stamp you create as its author, so reviewers can see who placed it. Set it before you upload the PDF. It's optional, and leaving it blank creates stamps without a name attached.

Can I put the same stamp on every page at once?

No. Stamps are placed one at a time on the page you're viewing, and you can move and resize each one before saving. If you need an identical mark on all pages, use the image mode in Add Watermark, which can apply one image to every page in a single step.

Are the stamps permanent, or can they be removed later?

Stamps are saved as PDF stamp annotations, so a PDF editor can still select, move, or delete them. If you want them merged into the page content so they can't be lifted off, run the saved file through Flatten PDF.

How do I move or resize a stamp after placing it?

Click the stamp in the viewer to select it, then drag it to a new position or pull its corner handles to change the size. Nothing is final until you click Save Stamped PDF, so you can adjust as much as you like first.

What's the difference between this and Sign PDF?

Sign PDF is built for signatures: you draw one, type one, or upload one and place it on the page. Add Stamps is for reusable image marks such as seals, RECEIVED stamps, or QC stamps, with your name recorded as the author of each one.

Does the stamp tool work on password-protected PDFs?

If the file needs a password to open, the tool asks for it before loading the viewer. You need the open password; the tool doesn't bypass encryption.

Is my document uploaded when I stamp it?

No. The viewer, the stamp editor, and the export all run in your browser, and the stamped PDF is written on your device. Nothing is sent to a server, which matters when you're stamping contracts, inspection reports, or notarized documents.
