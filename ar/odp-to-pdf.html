الأسئلة الشائعة

Can I convert a Google Slides presentation to PDF with this tool?

Yes, if you first download it from Google Slides as an ODP file using File > Download > ODP Document. Upload that .odp here and each slide becomes one PDF page.

Are speaker notes included in the PDF?

No. Only the slides themselves are rendered, one per page. Export the notes separately from Impress or Google Slides if you need them alongside the slides.

What happens to animations and slide transitions?

They're dropped, since a PDF page is static. Text, images, shapes, and slide backgrounds all appear as they do on the slide, but nothing moves or fades.

Does the PDF keep the slide size and layout?

Each slide is rendered at its original dimensions, so a 16:9 deck produces wide pages and a 4:3 deck produces squarer ones. Content is placed where it sits in the presentation.

Can I convert PowerPoint files here too?

This tool only accepts .odp files. For .pptx and .ppt decks use PowerPoint to PDF, which runs on the same LibreOffice engine.

Why is the first ODP conversion slower than later ones?

The LibreOffice engine has to download the first time you use it in a session, which the notice on the page mentions. Later conversions reuse the cached engine and start immediately.

What do I get if I convert several presentations at once?

A single presentation downloads directly as a PDF. Several are bundled into odp-to-pdf.zip, with one PDF named after each source file.

Are my slides uploaded to a server during conversion?

No. The LibreOffice engine runs in your browser as WebAssembly, so the presentation is rendered and saved as a PDF on your own device. Unreleased decks and internal material stay local.
