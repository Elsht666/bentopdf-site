よくある質問

What counts as an annotation here?

Everything stored in a page's annotation list: sticky notes and comments, highlights, underlines, strikethroughs, freehand ink, stamps, shapes, text boxes, clickable links, and file attachments. Page text, images, and vector graphics are never touched.

Will my form fields survive?

No. Form fields are stored as widget annotations, so they're removed along with everything else and any typed-in values disappear with them. If you want the filled-in values to stay visible, run Flatten PDF first, then remove annotations.

Does it remove watermarks?

Only watermarks that were added as annotations. Watermarks drawn into the page content itself stay in place, since they're part of the page graphics rather than a separate object.

Can I remove only some annotations instead of all of them?

Not with this tool; it clears every annotation on every page in one pass. To delete individual comments or highlights, open the file in the PDF Editor and remove them one at a time.

Why are some highlights still there after processing?

They were flattened: a previous tool merged them into the page graphics, so they're no longer separate annotation objects. Flattened markup can't be removed by this tool.

Does the text stay selectable, and do bookmarks survive?

Yes to both. The file is edited at the object level without re-rendering pages, so text remains selectable and searchable, and bookmarks, page order, and page sizes are unchanged. Links lose their click action, though the visible link text stays.

Will a digital signature stay valid?

No. Signature fields are annotations and are removed, and saving a modified copy invalidates an existing signature anyway. Remove annotations before signing, not after.

Is the PDF uploaded to strip the comments?

No. The annotations are removed with pdf-lib in your browser and the cleaned copy downloads under the original filename, so a heavily annotated contract never leaves your machine.
