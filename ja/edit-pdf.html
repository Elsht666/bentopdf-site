よくある質問

Can I change the existing text in my PDF with this editor?

This editor works on top of the page: highlights, comments, shapes, images, freehand drawing, redaction, and new text boxes. To rewrite text that's already in the document, use Edit PDF Text, which lets you click a paragraph and edit it in place.

Will my annotations show up in Acrobat, Preview, or Chrome?

Yes. Highlights, comments, shapes, and drawings are saved as standard PDF annotations, so other viewers display them and can usually edit or delete them. Text boxes are written into the page as regular text on download, so they look identical everywhere but can't be moved afterward.

Is the redaction permanent?

Yes. Applying a redaction removes the content underneath the marked area from the file rather than covering it with a box, so the text can't be recovered by copying or searching. Open the downloaded file and check before you share it.

Can I open more than one PDF at a time?

Up to 10 documents can be open at once, each in its own tab above the viewer. Adding more files opens more tabs, and removing a file from the list closes its tab.

Does the editor save my changes automatically?

No. Everything stays in your browser's memory until you click Download Edited PDF, and closing or refreshing the tab discards the changes. Download before you leave the page.

Why can't I highlight text on my scanned PDF?

Highlight, underline, and strikethrough attach to real text, and a scanned page is only an image. Run the file through OCR PDF first to add a text layer, or mark it up visually with the pen or rectangle tools.

Can I add text in Chinese, Japanese, Arabic, or other non-Latin scripts?

Yes. When a text box contains characters outside the basic Latin set, the editor fetches a matching Noto font and embeds it in the PDF so the text renders correctly in other viewers.

Does the editor upload my PDF?

No. The editor runs a PDF engine (PDFium compiled to WebAssembly) inside your browser. The only network requests are for the editor's code and optional font files; the document itself never leaves your device.
