Pengaturan Fitur Lanjutan

Konfigurasi modul pemrosesan eksternal untuk mengaktifkan fitur PDF lanjutan. Modul-modul ini opsional dan dilisensikan secara terpisah.

Sudah dikonfigurasi dan siap digunakan. Modul pemrosesan lanjutan dimuat secara otomatis dari CDN. Anda dapat menimpa URL di bawah ini jika perlu menggunakan sumber kustom (mis., untuk penyebaran air-gapped atau self-hosted).

PyMuPDF

Mesin Pemrosesan Dokumen

Belum Dikonfigurasi

Mengaktifkan: PDF ke Teks, Markdown, SVG, DOCX, Excel • Ekstrak Gambar/Tabel • Konversi Format

Direkomendasikan: https://cdn.jsdelivr.net/npm/@bentopdf/pymupdf-wasm@0.11.16/

Ghostscript

Mesin Konversi PDF/A

Belum Dikonfigurasi

Mengaktifkan: Konversi PDF/A-1b, PDF/A-2b, PDF/A-3b • Font ke Outline

Direkomendasikan: https://cdn.jsdelivr.net/npm/@bentopdf/gs-wasm@0.1.1/assets/

CoherentPDF

Mesin Bookmark & Metadata

Belum Dikonfigurasi

Mengaktifkan: Pisah berdasarkan Bookmark • Edit Bookmark • Metadata PDF

Direkomendasikan: https://cdn.jsdelivr.net/npm/coherentpdf@2.5.5/dist/
