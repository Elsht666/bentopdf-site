Veelgestelde vragen

How do I open a .pub file without Microsoft Publisher?

Upload the .pub file here and click Convert to PDF. A LibreOffice engine compiled to WebAssembly runs in your browser, reads the Publisher file, and writes a PDF you can open on any device, so you don't need Publisher or any other Microsoft software installed.

Will the layout look the same as in Publisher?

Text, images, and text boxes are placed according to the original layout, and most flyers and newsletters convert well. Layered text boxes and tightly positioned elements can shift slightly, and fonts that aren't standard system fonts may be substituted, so check the output when exact positioning matters.

Why does the first Publisher file take longer?

The conversion engine is roughly 75 MB compressed and is downloaded and started the first time you convert in a session, with a progress indicator showing how far along it is. After that, additional files convert much faster.

Can I convert several Publisher files at once?

Add multiple .pub files, remove any you don't want, and convert them together. A single file downloads as a PDF with the same base name; several are packaged into pub-to-pdf.zip, with duplicate names given a numbered suffix.

Can I convert a PDF back into a Publisher file?

No, the conversion is one way, from .pub to PDF. If you need an editable result, convert the PDF with PDF to Word afterward and rebuild the layout there.

Is the text in the converted PDF selectable?

The PDF is generated from the document's text objects, so text stays selectable and searchable rather than being flattened into an image. Text that was placed in the original as a picture stays a picture.

Is my Publisher file uploaded to a server?

No. The whole conversion happens inside your browser, so the .pub file and the resulting PDF never leave your computer. Client artwork, unreleased newsletters, and event programs stay private.
