常見問題

Will the PDF keep the formatting, images, and fonts from my EPUB?

Text, images, tables, and embedded fonts carry over. Because the reflowable book is laid out into fixed pages, the page breaks won't match what you see in an ebook reader. For heavily styled EPUBs, check the first few pages of the output to confirm the layout.

Can I convert a DRM-protected EPUB from Kindle, Apple Books, or Kobo?

No. The tool reads the EPUB file directly and doesn't remove DRM, so protected books fail to convert. It works with DRM-free EPUB files.

Does it support both EPUB 2 and EPUB 3?

Yes, both versions convert. EPUB 3 extras such as embedded audio and video have no PDF equivalent and are dropped, while the text, images, and tables are kept.

Can I convert several EPUB files at once?

Yes. Add multiple files and click Convert to PDF; the results download as epub-converted.zip with one PDF per book. A single file downloads directly as a PDF with the same base name.

Can I choose the page size, margins, or font size?

Not in this tool. There are no settings; the PyMuPDF engine renders the book with its default layout into standard page dimensions.

Is the text in the converted PDF selectable and searchable?

Yes. The EPUB text is written into the PDF as real text rather than page images, so you can search, select, copy, highlight, and annotate it in any PDF reader.

Is my ebook uploaded to a server for conversion?

No. The PyMuPDF engine loads into your browser as WebAssembly and renders the book there, so the EPUB never leaves your device. Large books with many images just take a little longer on slower machines.

Why does the first conversion take longer than later ones?

On the first run the browser downloads the PyMuPDF engine before it can start. After that the engine stays loaded, so converting more books in the same session starts right away.
