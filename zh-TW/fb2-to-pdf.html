常見問題

What is an FB2 file?

FB2 is the FictionBook 2 ebook format, an XML-based format that is common in Russia and Eastern Europe. It stores the book's text, chapter structure, and any embedded images in a single file, but many readers and phones outside that region can't open it, which is why converting to PDF helps.

Does the conversion keep chapters, formatting, and images?

Chapter breaks, basic text formatting, and images embedded in the FB2 file are all carried into the PDF. The PyMuPDF engine reads the XML structure directly, so nothing needs to be configured.

Can I convert an .fb2.zip file?

Not directly. The tool only accepts plain .fb2 files, so extract the archive first and upload the .fb2 inside it.

Can I convert several FB2 books at once?

Select or drop as many files as you like and click Convert to PDF. A single book downloads as a PDF with the same name, while several are packed into fb2-converted.zip with one PDF per book.

Can I change the page size or font before converting?

No. There are no layout options in this converter; the engine paginates the book with its default page size and typography. If you need a different page size afterward, run the result through Fix Page Size.

Will Russian or other Cyrillic text convert correctly?

FB2 files are Unicode XML and the converter renders Unicode text, so Cyrillic books convert with their original characters intact. The text stays selectable and searchable in the PDF.

Is my ebook uploaded during conversion?

No. The FB2 file is parsed and laid out by a PDF engine running in your browser, and only the finished PDF is saved to your device. Nothing is sent to a server, so the conversion also works for drafts and personal documents.

Why does the PDF have a different number of pages than my e-reader shows?

FB2 is a reflowable format, so page counts depend on screen size and font settings in each reader. The PDF fixes the layout at conversion time, which usually produces a different, and now permanent, page count.
