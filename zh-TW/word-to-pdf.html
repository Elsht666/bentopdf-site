常見問題

Do I need Microsoft Word installed to convert Word to PDF?

No. The conversion is done by LibreOffice compiled to WebAssembly running inside your browser, so it works on any computer, tablet, or phone with a modern browser and no Office license. The engine is about 77 MB and downloads on first use, so the first conversion of a session takes longer.

Can I convert Google Docs or Apple Pages files?

For Google Docs, download the document as .docx from File > Download and convert that. Pages files aren't supported; export them as Word or PDF from Pages first. The tool accepts .doc, .docx, .odt, and .rtf.

Will headings become PDF bookmarks, and do links stay clickable?

Yes, as long as the headings use Word's heading styles; LibreOffice's PDF export turns them into an outline, and hyperlinks in the document remain clickable in the PDF.

Why do fonts look different in the PDF?

Only fonts bundled with the engine are available, so a document set in a font that isn't embedded in the file is rendered with the closest substitute. The layout stays close, but line breaks can shift; embedding fonts in the .docx before converting avoids this.

Do tracked changes and comments appear in the PDF?

The document is rendered the way LibreOffice Writer displays it, so accept or reject tracked changes and delete comments in Word before converting if you want a clean PDF.

Can I convert several documents at once?

Yes. A single file downloads as a PDF with the same base name; multiple files are delivered as word-converted.zip with one PDF each, and duplicate names are numbered automatically.

What doesn't convert well?

Macros, ActiveX controls, and complex SmartArt may not render correctly, and Chinese, Japanese, Korean, or Indic text may show fallback fonts or boxes because those fonts aren't bundled. Standard text, tables, images, headers, footers, and footnotes convert reliably.

Is my document uploaded to a server for conversion?

No. The LibreOffice engine runs entirely inside your browser tab, so a resume, contract, or medical letter is converted on your own device and never sent anywhere.
