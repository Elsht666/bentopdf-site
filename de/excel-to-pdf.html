Häufig gestellte Fragen

Which spreadsheet formats can I convert to PDF?

The tool accepts .xlsx and .xls Excel workbooks, OpenDocument .ods files from LibreOffice Calc, and .csv files. You can mix formats in the same batch and convert them all at once.

Does it convert all sheets in the workbook or just the first one?

All sheets are included in the PDF. The LibreOffice engine follows each sheet's own page setup, print area, and scaling, so Print Preview in Excel is a good guide to what you'll get.

Will formulas and charts survive the conversion?

Charts are rendered into the PDF, and formulas appear as their computed values rather than the formula text. Cell formatting such as fills, borders, fonts, and number formats is preserved.

How do I stop a wide spreadsheet from being cut across several pages?

There are no layout options in the tool itself, so set the orientation, print area, and fit-to-width scaling in Excel or LibreOffice Calc before uploading. The converter reads those settings from the file and lays out the PDF accordingly.

Why does the first conversion take a while to start?

The browser-based LibreOffice engine is downloaded the first time you convert, which can take a moment on a slow connection. After that it stays cached for the session, so further conversions start right away.

What do I get when I convert several spreadsheets at once?

One file downloads directly as a PDF with the same name as the spreadsheet. Two or more files are bundled into excel-converted.zip with one PDF per spreadsheet.

Should I use Excel to PDF or CSV to PDF for a .csv file?

Excel to PDF runs a CSV through the full LibreOffice layout engine, which is heavier but handles long rows and print settings the way a spreadsheet would. CSV to PDF is a lighter, faster option for plain tabular data without formatting.

Is my spreadsheet uploaded to a server for conversion?

No. The LibreOffice engine runs inside your browser through WebAssembly, so the workbook is opened, rendered, and saved as a PDF on your own device. Financial data and personal records never leave your computer.
