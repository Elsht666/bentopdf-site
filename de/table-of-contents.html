Häufig gestellte Fragen

How do I add a table of contents page to a PDF?

Upload a PDF that has bookmarks, set the title, font size, and font, and click Generate Table of Contents. A new page listing every bookmark with its page number is inserted at the front of the document, and the file downloads under its original name.

Why does it say my PDF has no bookmarks?

The TOC is built entirely from the PDF's bookmark outline, not from headings in the text, so a document without bookmarks has nothing to list. Create them first with Edit Bookmarks, then run this tool on the saved result.

Are the entries in the table of contents clickable?

Each entry links to the page it refers to, so readers can jump straight there in any viewer that supports links, and the printed page number is there for paper copies.

Does it handle nested bookmarks?

Sub-bookmarks are indented under their parent entries, so a chapter and section hierarchy comes through as a multi-level list.

Which fonts and sizes can I use?

You can pick from the 12 standard PDF fonts, which are Times, Helvetica, and Courier in regular, bold, italic, and bold italic, at sizes from 10pt to 72pt; Helvetica at 12pt is the default. These built-in fonts cover Latin text, so bookmark titles in other scripts may not display correctly.

Will the new TOC page mess up my existing bookmarks or page numbers?

Existing bookmarks are kept and still point at the right pages after the new page goes in at the front. Numbers printed on your pages don't change, so a page labeled 1 is now the second physical page; tick Add bookmark for TOC page if you want the TOC itself listed in the outline.

Can I add a table of contents to a PDF I just merged?

As long as the merged file has bookmarks, it works like any other PDF. Generate the TOC as the last step so the page numbers match the final page order.

Is my PDF uploaded to generate the table of contents?

No. The bookmark outline is read and the TOC page is typeset by a cpdf engine running as WebAssembly in a background thread of your browser, and the updated file is downloaded from there. The document never leaves your device.
