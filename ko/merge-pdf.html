    자주 묻는 질문

    Does merging keep bookmarks?

    Yes. The merge is done with the CoherentPDF engine, which carries each file's bookmarks into the combined document so the outline stays navigable. Page content and annotations are copied as they are.

    Can I merge only some pages from each file?

    Yes. In File Mode, type a range such as 1-3, 5 in the Pages box next to a file to include just those pages, or leave it blank for the whole file. In Page Mode every page from every file appears as a thumbnail you can drag into any sequence, including interleaving pages from different documents.

    What order will the files be in?

    The order shown in the list, top to bottom. Drag entries to rearrange them before merging, and use Add More Files to append documents without losing the arrangement you already have.

    Why do page numbers look wrong in the merged PDF?

    By default the merged file uses plain numbering from 1 to N. If the originals used page labels such as i, ii, iii or A-1, turn on Keep original page labels to preserve them, keeping in mind that two files with the same labels will produce duplicates. To print visible numbers on the pages themselves, use Page Numbers.

    Why is the merged file so large?

    Each file's fonts and images are copied as they are, so the result is roughly the combined size of the inputs, and when several files embed the same font each copy is kept. Check Remove duplicate fonts to fold identical fonts into one; for more savings, run the result through Compress PDF.

    Can I merge PDFs that have different page sizes or orientations?

    Yes. Pages keep their own size and rotation, so a landscape A3 drawing can follow a portrait Letter page without being scaled. For a uniform size afterward, run the merged file through Fix Page Size.

    Are the PDFs uploaded to a server to be merged?

    No. The files are combined inside your browser by the CoherentPDF WebAssembly module and the merged PDF is written to your downloads folder, so contracts and statements never leave your machine.

    Can I merge password-protected PDFs?

    If a file needs a password to open, the tool asks for it when you add the file and then merges the decrypted pages. The merged output has no password; add one afterward with Protect PDF if needed.
