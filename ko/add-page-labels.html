페이지 레이블 추가

로마 숫자, 접두사, 사용자 지정 시작값으로 PDF 페이지 레이블을 적용합니다.

클릭하여 파일 선택 또는 파일을 끌어다 놓으세요

PDF 파일

파일이 기기 밖으로 나가지 않습니다.

레이블 작동 방식

  • 모든 페이지에 레이블을 적용하려면 페이지 범위를 비워 두세요.
  • 앞부분에는 로마 숫자, 본문에는 십진 번호 같은 스타일을 사용하세요.
  • 시작값 0과 함께 접두사를 사용하면 A-0, A-1, A-2 같은 레이블을 만들 수 있습니다.
  • 하나의 규칙이 1-9,30-40 또는 홀수 페이지 같은 비연속 범위를 사용할 때 진행 옵션을 켜세요.

레이블 규칙

이 도구는 브라우저에서 CoherentPDF를 사용합니다. CoherentPDF가 구성되지 않은 경우 WASM 설정에서 설정하라는 안내가 표시됩니다.

자주 묻는 질문

How do I label appendix pages A-1, A-2, A-3?

Add a rule for the appendix page range, keep Decimal Arabic as the style, and type A- in the Label Prefix field. With the default start value of 1 the pages become A-1, A-2, A-3, and a second rule with the prefix B- handles the next appendix.

Can page numbering start at 0 or at a number other than 1?

Each rule has a Start Value field that defaults to 1. Set it to 0 for zero-based numbering, or to any other number, for example 15 so a chapter extracted from a longer book keeps its original page numbers.

What does 'Continue numbering across disjoint ranges' do?

Turn it on when one rule covers pages that aren't contiguous, such as 1-9,30-40 or odd, and you want the labels to keep counting in sequence across the gap. With it off, each separate block of pages starts again from the start value.

What happens to the page labels the PDF already has?

The 'Remove existing page labels' box is checked by default, so the old labels are cleared before your rules are applied. Uncheck it if you only want to relabel some pages and keep the existing labels on the rest.

Which page range formats can I type?

Leave the field empty to cover every page, or use forms like 1-4, 7, odd, or 1-9,30-40. Page numbers refer to physical positions in the file, not to labels the PDF may already display.

Can I add labels to a password-protected PDF?

Not directly. The tool stops with a Protected PDF message, so remove the password first with Unlock PDF and then upload the copy that no longer needs one.

Why does the tool ask me to configure CoherentPDF?

Page labels are written by the CoherentPDF engine, which normally loads from a CDN the first time you use the tool. If that default has been turned off in a self-hosted build, you'll be prompted to point WASM Settings at a copy of the library.

How do I check that the labels were applied?

Open the downloaded PDF in a reader that displays page labels, such as Adobe Acrobat or Firefox's built-in viewer, and look at the page number box in the toolbar. It shows the label, for example iv or A-1, instead of the plain page index.
