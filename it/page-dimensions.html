Domande frequenti

How do I check whether my PDF is A4 or Letter?

Upload the file and the analysis runs immediately. The summary shows the total page count and how many distinct sizes appear, and the table lists each page's width and height next to the matched standard size, so a plain A4 or Letter document shows one size across all pages.

Which standard paper sizes does it recognize?

A3, A4, A5, Letter, Legal, and Tabloid, in either portrait or landscape, matched within one point of the official dimensions. Anything else is reported as Custom with its exact measurements.

What does the Mixed Sizes warning mean?

More than one width and height combination was found in the document, and the summary breaks down how many pages use each. A rotated page counts as a separate size from its upright twin, so a landscape A4 page in a portrait A4 file triggers the warning. To make everything uniform, use Fix Page Size.

Can I see the sizes in inches or millimeters instead of points?

Use the units menu to switch the whole table between points, inches, millimeters, and pixels. Pixels are calculated at 96 PPI, which matches how browsers and most screen tools treat PDF pages.

What does the Rotation column tell me?

It shows the rotation attribute stored on the page, in degrees. A page can look upright in a viewer while carrying a 90 or 270 degree rotation, which trips up some print and conversion workflows, and Rotate PDF can normalize it.

Can I export the results?

Click Export to CSV to download page-dimensions.csv with one row per page: page number, width, height, standard size, orientation, aspect ratio, area, and rotation, in whichever unit is selected. It opens directly in Excel or Google Sheets.

Does this tool change my PDF?

No. It only reads the page tree and reports what it finds; nothing is rewritten, and the only download offered is the optional CSV.

Is the PDF uploaded for analysis?

No. The file is parsed in your browser and the measurements are computed locally, which is also why the results appear as soon as the file is loaded.
