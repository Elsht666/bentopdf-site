Často kladené otázky

Why does my first PowerPoint conversion take a while?

The converter is a full LibreOffice build compiled to WebAssembly, about 75 MB, that your browser downloads and starts the first time you convert. Once loaded it stays ready, so a second presentation in the same session converts far faster.

Will animations, transitions, and embedded videos show up?

No. Every slide is captured as a static page, so animations and transitions are dropped and a video appears only as whatever the slide shows in its place. Replace videos with a screenshot before converting if you need a visual.

Are speaker notes included?

Not in this export; only the slides are rendered, one per page. If you need a notes version, print to PDF from PowerPoint's notes view instead.

Which file types are accepted?

Modern .pptx, legacy .ppt, and OpenDocument .odp presentations, in any mix, several at a time. Keynote and Google Slides decks need to be exported to .pptx first.

What page size do the PDF pages have?

Each page matches the slide's own dimensions, so a 16:9 deck produces landscape pages in that ratio rather than being forced onto Letter or A4. If you need a standard paper size for printing, run the result through Fix Page Size.

Why do some fonts look different in the PDF?

The in-browser engine ships with its own fonts and can't see fonts installed on your computer, so a deck that uses a font it doesn't have is rendered with a substitute, which can shift line breaks. Sticking to common fonts keeps the layout closest to the original.

What do I get when I convert several presentations at once?

Each file becomes a separate PDF with the original name, and they're bundled into powerpoint-converted.zip. A single file downloads straight away as a PDF.

Is my presentation uploaded to a server?

No. The LibreOffice engine is downloaded to your browser and runs there; the presentation is opened and converted on your own machine. Confidential pitch decks and internal reviews never leave your device.
