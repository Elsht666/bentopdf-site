Často kladené otázky

What happens to photos and colored graphics when I invert a PDF?

Every pixel is flipped to its complementary value, so photos look like film negatives and brand colors shift (blue turns orange, red turns cyan). The tool suits text-heavy documents where you want light text on a dark page; for brightness or contrast changes without inverting images, use Adjust Colors.

Will I still be able to select or search text after inverting?

No. Each page is rendered as an image, inverted, and rebuilt as an image-only PDF, so the text layer is gone. If you need searchable text again, run the inverted file through OCR PDF.

Does the inverted PDF look blurry?

Pages are rendered at 1.5x scale, roughly 108 dots per inch. That's sharp on a screen at normal zoom, which is where dark-mode reading happens, but it can look soft if you print the file or zoom in far.

Why is the output file larger than the original?

The inverted pages are stored as full-page PNG images instead of text and vector drawings, which often takes more space. For a smaller file, pass the result through Compress PDF.

Are hyperlinks, bookmarks, and form fields kept?

No. Because the output is a fresh image-based document, interactive elements such as links, form fields, comments, and bookmarks are not carried over. Keep the original if you need them.

Can I invert only some pages?

Not with this tool; it processes every page. If you only want a few pages inverted, separate them first with Split PDF, invert that part, and merge the pieces back together.

Does it work on scanned documents?

Yes. Scans are already images, so they invert cleanly, and it can rescue a scan captured as a negative or with reversed exposure. Grayscale scans keep their gray levels, just reversed.

Is my document uploaded to be inverted?

No. Rendering and pixel inversion happen on a canvas in your browser, and the new PDF is assembled locally. Nothing leaves your computer, and there's no server queue, so the speed depends only on your device.
