# PDF 工具箱（个人自用版）

基于 BentoPDF 的个人自用精简站点：一套在浏览器本地运行的 PDF 工具集，支持编辑、合并、拆分、转换、保护、压缩等处理。

所有文件处理均在本机浏览器内完成（WebAssembly + 本地计算），不会上传到任何服务器。

## 功能特性

- 100+ 本地 PDF 工具（编辑 / 合并 / 拆分 / 转换 / 加密 / 压缩 / 签名等）
- 热门工具自定义排序：
  - 桌面端：右键卡片激活操作（← 左移 / → 右移 / × 移除）
  - 移动端：长按卡片激活
  - 从「All Tools」点击 ＋ 添加到热门（青绿色按钮）
  - 点击「恢复默认」还原初始热门列表
  - 自定义配置保存在浏览器本地（localStorage），仅当前浏览器生效
- 误触保护：编辑状态下点击卡片或页面任意位置即取消编辑，不会误进入工具
- 页面默认仅「热门工具」展开，其余分类折叠
- 已去除原站的商业化内容（官网外链、赞助、广告、社区等），纯自用

## 本地运行

```bash
npm install
npm run dev
```

## 构建部署

```bash
npm run build
```

构建产物输出到 `dist/`，为纯静态文件，可部署到任意静态托管（Cloudflare Pages / GitHub Pages / Nginx 等）。
