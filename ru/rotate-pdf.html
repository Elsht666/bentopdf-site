Часто задаваемые вопросы

Can I rotate just one page instead of the whole document?

Yes. Every page shows as a thumbnail with its own left and right buttons, so a single sideways scan in a 40-page file can be fixed on its own. The buttons at the top rotate every page at once when the whole document is the wrong way up.

How do I rotate a page 180 degrees?

Click the same direction twice. Rotations add up in 90-degree steps, so two clicks give 180 and three clicks give 270, the same as one click the other way. The thumbnail updates so you can see the current state before saving.

Does rotating reduce the quality of the pages?

No. The tool changes each page's rotation attribute rather than re-rendering anything, so text stays selectable, images keep their resolution, and the file size stays about the same.

Will the rotation stick when I open the file in another app or print it?

Yes. The rotation is written into the PDF page itself, which every viewer and printer honors, unlike the temporary rotate button in a viewer that resets when you close the file.

Can I rotate by an angle other than 90 degrees, like to straighten a tilted scan?

Not here; this tool works in 90-degree steps only. Use Rotate by Custom Degrees for arbitrary angles, or Deskew PDF to straighten scans automatically.

Can I rotate only the odd or even pages?

There's no page selection or range field in this tool; you either rotate pages one at a time with their buttons or all of them together. For selecting groups of pages, PDF Multi Tool is the better fit.

Is my PDF uploaded to rotate its pages?

No. The thumbnails are rendered by your browser and the rotated file is written locally, so the document never leaves your computer. The rotated PDF downloads under the original file name.

Does rotating keep my bookmarks?

Page content, images, and annotations come through unchanged, but bookmarks are not carried over, because the rotated file is built from copied pages. A document that relies on its outline will need it added back with the Bookmark tool.
