Часто задаваемые вопросы

Can I type text instead of uploading a file?

Yes. Switch the toggle to Type Text, paste or type into the editor, and click Create PDF. It's the quickest way to turn clipboard content into a PDF without saving a .txt file first.

Which fonts and page sizes are available?

Four fonts: Helvetica (sans-serif), Tiro and Times (serif), and Courier (monospace), at any size from 6 to 72 points. Page sizes cover the ISO A, B, and C series from A0 to C10 plus US Letter, Legal, Tabloid, Ledger, and 11 x 17, with A4 as the default.

What happens if I upload several .txt files?

Their contents are joined into a single PDF, in the order listed, with a blank line between each file. There's no page break between files, so if each one needs its own pages, convert them one at a time.

Does it handle right-to-left languages like Arabic or Hebrew?

Yes. When the text contains Arabic, Hebrew, Persian, or Urdu characters, the direction switches to right-to-left and the text is right-aligned, both in the editor and in the PDF.

Can I change the margins?

No. Margins are fixed at 1 inch (72 points) on every side, and text wraps to fit within them at the chosen font size. Pick a larger page size if you need more text per page.

Will long lines wrap or get cut off?

Lines wrap automatically at the right margin, and line breaks from the source are kept. Courier gives every character the same width, which suits code and logs.

What filename does the PDF made from my text file get?

The download is always named text_to_pdf.pdf, regardless of the input file name. Rename it after downloading if you're producing several.

Is the text I type sent to a server?

No. The PDF is generated by a PDF engine running in your browser, so notes, logs, or credentials pasted into the editor never leave your device. The engine itself is downloaded on first use, which is why the first conversion pauses briefly.
