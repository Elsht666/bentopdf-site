Ofte stillede spørgsmål

How do I change the background color of a PDF without losing the text?

Upload the PDF, pick a color, and the tool draws a solid rectangle behind each page and places the original page content on top of it. The text stays real text, so it remains selectable and searchable, and the page dimensions don't change.

Why didn't the background color show up on some pages?

The color sits underneath the existing content, so any page that already has an opaque background covers it up. Scanned pages, which are usually one full-page image, and pages with a drawn white background are the most common cases.

Does the color apply to every page or can I pick specific pages?

There's no page range option, so the same color is applied to every page in the document. To color only certain pages, pull them out with Split PDF, color that file, and merge it back.

What colors work best as a PDF background?

Light, muted tones such as cream, ivory, or pale yellow keep black text readable, which is why the default is a light yellow (#FFFFCC). A dark background makes normal black text hard to read because the text color isn't changed; use Change Text Color on the result if you want light text on a dark page.

Will links, form fields, or bookmarks survive the color change?

No. Each page is re-embedded as a drawing on top of the color layer and written into a new file, so link annotations, form fields, comments, and bookmarks aren't carried over. Change the background first and add those elements afterward.

Does changing the background turn my pages into images or make the file bigger?

Pages aren't rasterized. The tool works at the PDF object level and only adds a filled rectangle per page, so fonts and vector graphics stay intact and the file size stays close to the original.

Is my PDF uploaded when I change its background color?

No. The color layer is added by code running in your browser and the finished file is saved directly from the page to your device. The document isn't sent to a server at any point.

Can I change the background color of a password-protected PDF?

If the PDF needs a password to open, the tool prompts you for it and then processes the file as usual. The output is saved without that password, so protect it again with Protect PDF if you still need it locked.
